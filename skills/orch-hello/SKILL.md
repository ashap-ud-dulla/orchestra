# Hello

1. Take the job text from the first message (or "world" if there is none).
2. Write a file `hello.txt` in the current folder with one line: `Hello, <text>!`
3. Say in one short sentence what you wrote.

End with a WHAT I DID AND WHY section of one bullet and the line `ORCHESTRA:DONE`.
